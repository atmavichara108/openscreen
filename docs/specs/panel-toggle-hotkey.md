## Цель (слово владельца, basis: quoted)

«настоящий. панель должна открываться\закрываться по хоткею» — панель (главное окно)
должна переключаться по готкейу: нажатие скрывает видимое окно, повторное — возвращает.

## Scope

- `electron/main.ts`: функция `toggleMainWindow()`; обе привязки глобальной клавиши
  (`ipcMain "update-global-shortcut"` и `loadAndRegisterGlobalShortcut`) используют её.
- Tray-click и `second-instance` остаются на `showMainWindow` (не трогать).
- Вне scope: выбор самой клавиши (умолчание `Ctrl+Shift+O` не меняется), qtile-интеграция,
  упаковка, пресеты экспорта.

## Поведение (критерии)

1. Окно скрыто или не создано → нажатие создаёт/возвращает окно (`restore` + `show` + `focus`).
2. Окно видимо и не свёрнуто → нажатие **скрывает** окно через `hide()` (НЕ `close`/`destroy`):
   процесс, трей и глобальная клавиша живы; несохранённое в редакторе не теряется,
   т.к. `hide` идёт мимо close-подтверждения.
3. Окно свёрнуто → нажатие восстанавливает (`restore`, не hide).
4. Повторное нажатие возвращает окно (обратимость).
