## Что подходит нам из коробки

- **Язык:** локаль `ru` уже есть (15 локалей), проверка полноты — `npm run i18n:check`.
  Перевод на русский не требуется.
- **Захват под нашу платформу:** X11 → сначала портал (`xdg-desktop-portal` активен:
  PipeWire/dmabuf, GPU-кодек), затем прямой X11 через нативный helper; Wayland → PipeWire.
  У нас X11 — работают оба пути.
- **Курсор:** своя курсорная тема недоступна (правило платформы) — авто-зум строится по
  позиции курсора.
- **Горячие клавиши:** одна глобальная (открыть приложение, `Ctrl+Shift+O`,
  `electron/globalShortcut.ts`, дефолт `DEFAULT_OPEN_APP_BINDING`, меняется в настройках);
  шорткаты редактора — `src/lib/shortcuts.ts` + диалог `ShortcutsConfigDialog`
  (i18n-ключи — `src/i18n/locales/ru/shortcuts.json`). Конфликтов с нашим qtile нет.
- **Настройки записи** (`electron/app-settings.ts`): микрофон/камера/системный звук
  выключены по умолчанию; курсор `editable-overlay`; авто-зум включён; «скрытие иконок
  рабочего стола» — только mac/win.
- **Каталог записей:** по умолчанию `~/.config/openscreen/recordings`, переключаемый
  (`RecordingsDirManager` / `RecordingsLocationStore`).
- **Автообновление:** AppImage/NSIS/mac — для форка отключить.
