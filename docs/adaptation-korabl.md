## Найдено на машине (важно для экспорта)

- **Кодирование только софтверное:** `vaInitialize failed` (VAAPI), «Vulkan device
  has no H.264 encode queue» — аппаратных путей нет, и софтверный работает.
- **Заявленный fps не равен фактическому — зависит от размера кадра (пилот Лыхыбы 19.11):**
  60 fps достижимы на малых окнах. Замеры: 938×1016 → eff. 59.0 fps (median 16.7 мс);
  1706×2056 → 35.72 fps (p95 33.3 мс); 3840×2160 → 16.07 fps (p95 83.3 мс).
  `dropped=0` — недобор не отмечается кодом. **Следствие для адаптации:** пресеты
  считать софтверный путь по размеру кадра, а не объявленные 60/1.
- **Системный звук не пишется:** AAC-дорожка в контейнере есть, пакетов 0 — реальных
  узлов PipeWire нет (ALSA принадлежит PulseAudio). Дефолт «выкл» корректен;
  кандидат на будущее — источник-монитор PulseAudio.
- **Кириллица в CLI — mojibake:** «Партия приёмки» печатается как `ÐÑ...` (UTF-8,
  прочитанный как latin-1). Мелкий дефект кодировки вывода — правка форка.
- Экспорт (пилот): MP4 2414×1080 за ≈70 с машинного времени; GIF 1610×720 @15fps,
  1.75 МБ за ≈80 с. Оба — PASS.

1. **Кодирование/экспорт** — подтвердить работу без VAAPI (п. «Найдено»).
2. **Каталог записей** — выбрать наш (`~/Videos/screencasts` или иное) — решение

3. **Интеграция с qtile** — хоткей открытия/старта записи, поведение окна (floating,
   always-on-top HUD) — зона qtile-dev + Apps-dev.
   **Сделано (18.11, требование владельца):** панель открывается/закрывается по хоткею —
   `toggleMainWindow()` в `electron/main.ts`: глобальная клавиша (по умолчанию
   `Ctrl+Shift+O`) скрывает видимое окно (процесс, трей и шорткат живые; несохранённое
   в редакторе не теряется — путь `hide`, не `close`) и возвращает/создаёт скрытое.
4. **Приватность** — отключить телеметрию (usage ping) и автообновление в форке.
5. **Пресеты экспорта** под наши сценарии (демо/гифки для КРУК/Mail Hub) — ждём Apps-dev.
6. **Брендирование** — имя/иконка под Корабль при сохранении копирайта и MIT/NOTICE.
7. **Дистрибутив под Linux** — отдельная задача (по пилоту 19.11): сборка нативных
   частей проходит (`build:native:linux`, `build:native:compositor:linux` 3 мин 43 с,
   `fetch:ffmpeg:sdk`), но упаковка требует `libonnxruntime.so` (это **фоновый эффект
   камеры**, не STT), `whisper-stt-server` + `libggml*` (это STT). Первое —
   `fetch-onnxruntime.mjs` верхnerəppa знает только win/mac: **добавляю linux-x64**.
   Второе — требует `vulkan-headers` на хосте (зона владельца, команда выдана).
